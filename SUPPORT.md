# Support

This is a client-side static HTML tool — all computation runs in your browser.

## Getting Help

- **Bug reports:** Open an issue at https://github.com/totalwindupflightsystems/inference-estimator/issues
- **Feature requests:** Open an issue with the `enhancement` label
- **Questions:** Use GitHub Discussions

## Self-Help

- All model presets, pricing data, and formulas are embedded in the single `cluster-estimator.html` file
- Open the file in any modern browser — no server required
- No data leaves your machine; all calculations are local
