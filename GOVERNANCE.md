# Governance

## Decision Making

The project maintainer has final say on all decisions. Community input is welcome via GitHub issues and discussions.

## Roles

- **Maintainer:** Alexis Okuwa — code review, merging PRs, releases
- **Contributors:** Anyone submitting accepted PRs
